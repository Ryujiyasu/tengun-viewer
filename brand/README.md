# ブランド素材

葉月工業株式会社のロゴ。出典: <https://hatsuki.co.jp/>

| ファイル | 用途 |
|---|---|
| `hatsuki-logo.svg` | 明るい背景用（横組み・ロゴマーク＋ワードマーク） |
| `hatsuki-logo-white.svg` | 暗い背景用（白抜き・縦組み） |

ブランドカラー（ロゴの塗り色から）。

| 色 | 値 | 用途 |
|---|---|---|
| グリーン | `#008746` | アクセント |
| ブルーグレー | `#83A1B1` | 補助 |
| ダーク | `#231815` | 文字 |

## 注意

- ロゴは葉月工業株式会社の資産。改変・切り出しはしないこと
- ビューアには `tools/embed-brand.mjs` が SVG をそのまま JS に埋め込む。
  閉域網や file:// で開いても表示できるようにするため、外部ファイル参照にはしない
- 差し替えるときは、このフォルダの SVG を置き換えて `npm run build` し直す
