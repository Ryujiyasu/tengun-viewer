計測日: 2026-09-18

データ: 合成サンプル 1 工区（出来形 200 万点 / 起工測量 120 万点 / 設計 TIN 2,760 三角形）

### 分かったこと

**問題は GPU の有無ではなく、ハードウェアアクセラレーションが有効かどうか。**

計測に使った Intel UHD 630 は庁内 PC にもよくある内蔵 GPU だが、
それでも 60 fps 出る。一方、ソフトウェア描画に落ちると 5〜8 fps まで下がる。
操作はできるが快適ではない。

庁内 PC でアクセラレーションが切られている可能性は次の理由で無視できない。

1. **VDI / シンクライアント** — GPU が割り当てられていない
2. **グループポリシー** — Edge/Chrome には `HardwareAccelerationModeEnabled` があり、組織が切れる
3. **ブラウザの自動ブロック** — 既知の不具合があるGPU・ドライバの組み合わせは自動でソフトウェア描画に落ちる
4. ドライバ未更新

ただし**鹿児島市が実際にどうかは未確認**。これは推測で議論する必要がない。
ビューアに**診断情報パネル**を付けてあり、描画装置名と「ソフトウェア描画か否か」が
表示される。庁内 PC で軽量版 HTML を 1 回開いて読めば確定する。

## 3. 配布形態の検証

指示書が挙げた 3 方式のうち、A（file://）と C（Web サーバ）の両方を実機で確認した。

| 方式 | 結果 |
|---|---|
| **A. file:// で直接開く** | **動く。** 軽量版（単一 HTML）なら 58.7 MB まで確認済み。点は間引かれるが、判定値は全点で計算した値を表示する |
| **B. ローカル HTTP サーバ同梱** | **作らない。** 実行ファイルの持ち込みが禁止されている環境では使えない |
| **C. 閉域内 Web サーバ** | **動く。** HTTP Range リクエストで必要なノードだけ取得する。Range 非対応のサーバでも 1 度だけ全体取得して動作する |

フル版を file:// で開いた場合は、CORS で読めない旨と軽量版を使うよう日本語で案内する。

## 4. WebGL2 が使えない場合

WebGL2 を無効化した状態で確認した。

- 原因（WebGL1 のみ / 非対応ブラウザ / 無効化）を切り分けて**日本語で表示する**
- 対処方法（Edge / Chrome それぞれの設定手順）を併記する
- **Canvas 2D モードに自動で落ちる。** 平面図・較差カラーマップ・断面図・帳票は見られる
- 警告は画面上部のバナーで、点群を覆い隠さない

## 5. ブラウザでの取り込み

CLI を通さず、ビューアに LAS/LAZ と設計 LandXML を直接投入する経路も実装した。
受注者が納品前に自分で確認するための入口。

| データ | 所要（ブラウザ内、Web Worker） |
|---|---|
| 合成サンプル 200 万点 / 49.6 MB LAS | **14.6 s** |
| 実測 LAZ 11 万点 / 589 KB（PDAL テストデータ） | **5.8 s** |

**CLI で変換した場合と判定値が 10/10 項目一致することを自動試験で確認している。**
取り込みでも変換でも数字は変わらない。

判定・統計は**常に全点で計算する（間引かない）**。間引きは描画用の octree だけが行い、
数字には一切触れない。

LAZ は laz-perf（WASM）で解凍する。`.wasm` は base64 で HTML に埋め込んであるため、
file:// で開いた単一 HTML でも LAZ が開ける。
