# 出来形管理要領との対応

参照した要領:
**「３次元計測技術を用いた出来形管理要領（案）令和８年３月版」国土交通省**
<https://www.mlit.go.jp/tec/constplan/content/001880735.pdf>（470 ページ、2026-09-18 取得）

このファイルは、実装が要領のどこに対応し、どこが未確認かを残すためのもの。
規格値そのものは `spec-values.json` にある。

## 1. 較差の定義

要領（別紙１ 面管理編 第５章）は土工について次のように定めている。

> 標高較差は、各ポイントの標高値と、平面座標と同じ設計面上の設計標高値との差分として算出する。

> 水平較差は、当該ポイントを含み、かつ「法面や構造物の位置をコントロールする線形」に
> 直交する平面上で設計面の横断を見たとき、当該ポイントと同一標高値の横断上の点との距離として算出する。

つまり要領が認めるのは **標高較差** と **水平較差** の 2 つで、**法線方向較差は要領に無い**。

当初の設計指示は「のり面では鉛直較差は意味を持たないので法線方向較差を使う」としていた。
技術的な指摘としては妥当だが、要領はのり面についても標高較差で測り、そのかわり
**のり面の規格値を緩めている**（記載例では天端 ±50mm に対しのり面 ±80mm）。
勾配で鉛直較差が大きく出る分を規格値側で吸収する設計になっている。

法線方向較差で出した数字は、検査職員が見る出来形管理表の数字と一致しない。

### 実装

| 方式 | id | 要領 | 用途 |
|---|---|---|---|
| 標高較差 | `elevation` | あり | **判定の既定**。帳票の数字はこれ |
| 水平較差 | `horizontal` | あり | のり面で標高較差の代わりに使う場合 |
| 法線方向較差 | `normal` | **なし** | 表示専用。施工誤差の直感的な把握用 |

`--measure` で切り替えられる。要領外の方式を選ぶと CLI と画面の両方で警告を出す。
点群データには判定用と表示用の 2 つの較差を同時に格納してあり、画面で切り替えられる。

## 2. 判定の構造（様式-31-2）

要領の「出来形合否判定総括表」（様式-31-2、別紙１ 図１-２６〜２９）は
**部位ごと**に次を並べる。

| 測定項目 | 内容 |
|---|---|
| 平均値 | 棄却点を除く平均 |
| 最大値(差) | 棄却点を除く最大 |
| 最小値(差) | 棄却点を除く最小 |
| データ数 | 計測密度。規格値は 1 点/㎡以上 |
| 評価面積 | 水平投影面積 |
| 棄却点数 | 規格値は 0.3% 以下 |
| ばらつき | 規格値±50% 以内の割合 / ±80% 以内の割合 |

部位（天端・法面）は設計 TIN の勾配で振り分けている（既定 15° 以上を法面、
`--slope-threshold` で変更可）。評価面積は部位ごとの三角形の水平投影面積。

## 3. 未確認事項

実運用の前に確認が要るもの。

### 3.1 規格値の数値

要領は規格値を **「土木工事施工管理基準及び規格値（案）（国土交通省各地方整備局）」**
に委ねており、要領本文には数値表が無い。

`spec-values.json` に入れた数値は、要領の**様式記載例**（図１-２６〜２９）から
読み取った参考値であり、規格値表そのものではない。`source.verified` は `false` のまま。

確認先: 適用される施工管理基準の最新版。鹿児島市／鹿児島県がどれを適用するかも要確認。

### 3.2 棄却点の判定条件

様式には「棄却点数（規格値 0.3% 以下）」の欄があり、平均・最大・最小は
「棄却点を除く」と明記されている。しかし**棄却の条件そのものの明文規定は
要領本文から読み取れなかった**。

様式の記載例では、個々の計測値に対する規格値（天端 ±150mm / 法面 ±190mm）を
超えた点の数が棄却点数に一致するため、**「個々の計測値に対する規格値を超えた点を
棄却点とする」と解釈して実装している**。この解釈は未確認。

### 3.3 のり面を標高較差で見るか水平較差で見るか

要領は両方を認めている。どちらで管理するかは発注者との協議事項。

### 3.4 鹿児島市の適用範囲

市の試行要領（令和6年10月1日）は
**災害復旧工事・維持補修工事・降灰除去工事を対象外**としている。
法面・治山・砂防・災害復旧を主戦場とする事業者ほど、対象外の工事を多く抱える。

## 4. 実装していないもの

- 施工履歴データによる出来形管理
- 舗装工の層別の厚さ管理（直下層の実測値を使う計算）
- 平坦性
- 出来形数量の算出（土量 CSV は格子標高差による概算で、数量計算書の代わりにはならない）
