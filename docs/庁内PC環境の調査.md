# 庁内PC環境の調査

指示書 6.3 の未確定事項「庁内PCのブラウザとGPU設定」について、
公開情報で分かった範囲と、分からなかった範囲の切り分け。

調査日: 2026-09-18

## 結論

**鹿児島市の実際の環境は、公開情報からは分からなかった。** ただし、
**推測で議論する必要がない形にした。**

ビューアのトップページに環境チェックを置いてある。
庁内PCで 1 回開けば、WebGL2 の可否・描画装置名・ソフトウェア描画かどうかが
その場で表示され、結果をコピーして送れる。

<https://ryujiyasu.github.io/tengun-viewer/>

## 分かったこと

### 1. 自治体ネットワークの三層分離

2015 年の日本年金機構の情報流出を受け、総務省の指導で自治体のネットワークは
「マイナンバー利用事務系」「LGWAN 接続系」「インターネット接続系」の
3 層に分離されている。当初モデル（αモデル）の業務効率低下を受けて
β／β'モデルが提示され、2024 年 10 月には α'モデルが追加された。

**インターネット接続系では仮想ブラウザ（画面転送）が広く使われている。**
ブラウザの実行環境をインターネット接続系に置き、画面だけを LGWAN 系の端末へ転送する方式。

### 2. これが配布方法の選択に効く

| 開き方 | 経路 | WebGL の扱い |
|---|---|---|
| GitHub Pages の URL を庁内で開く | インターネット接続系 → **仮想ブラウザ経由の可能性** | 画面転送だと GPU が効かない恐れ |
| 単一 HTML をローカルで開く | 端末のブラウザで直接 | 端末の設定次第 |
| 庁内 Web サーバに置いて開く | LGWAN 系内で完結 | 端末の設定次第 |

**公開URLでの動作確認は、庁内の実際の使用環境の確認にはならない可能性がある。**
本命は単一 HTML をローカルで開いてもらうこと。トップページにもそう書いてある。

なお「仮想ブラウザだと WebGL が使えない」と明記した一次情報は見つけられなかった。
画面転送方式では GPU アクセラレーションが効かない構成が一般的、という一般論まで。

### 3. ハードウェアアクセラレーションが切られる理由

- **VDI / シンクライアント** — GPU が割り当てられていない
- **グループポリシー** — Edge/Chrome の `HardwareAccelerationModeEnabled` を組織が無効化できる
- **ブラウザの自動ブロック** — 既知の不具合があるGPU・ドライバの組み合わせは自動でソフトウェア描画に落ちる
- **ドライバ未更新** — 導入時のままの業務PC

いずれも鹿児島市に当てはまるかは未確認。

### 4. 他県は既に点群を一般公開している

| 自治体 | 時期 | 内容 |
|---|---|---|
| 長崎県 | 令和5年3月（試験公開）→ 8月（県内ほぼ全域） | 3D点群データをオープンデータ公開（「オープンナガサキ」）。LAS 形式 |
| 和歌山県 | 令和5年3月1日 | 統合型地理情報システムで点群データと **3D Web ビューアー** を公開。座標・距離・高さ・面積・断面線の計測が可能 |

**和歌山県は既に 3D Web ビューアーを県民向けに公開している。**
自治体が WebGL ベースの点群ビューアを一般公開すること自体は前例がある。

なお和歌山県のページには推奨ブラウザ・動作環境・WebGL に関する注意書きは
記載されていなかった。

また、和歌山県のビューアには計測機能がある。
指示書は計測ツールを「精度の担保について発注者と揉める元になる」として
P2 以降送りにしていたが、県レベルでは既に提供されている。

## 確認したいこと（市への質問案）

1. 庁内PCで <https://ryujiyasu.github.io/tengun-viewer/> は開けるか。開けた場合、環境チェックの結果はどう出るか
2. 単一 HTML ファイル（25MB）をメール添付または USB で受け取り、ダブルクリックで開けるか
3. インターネット接続系のブラウザは仮想ブラウザ（画面転送）か、端末のローカルブラウザか
4. 庁内 Web サーバに静的ファイルを置く手続きはどうなっているか
