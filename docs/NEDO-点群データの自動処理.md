# 点群データの自動処理

## 1. 何に困っているか

土木工事で ICT を活用すると、ドローンやレーザースキャナで現場の3次元点群が取れます。
しかし、**取ったあとの扱いが現場にも役所にも定着していません。**

**発注者が点群を見る手段がない。**
鹿児島市の地図基盤は2次元の「かごしまiマップ」で、3次元点群を前提とした業務フローが
ありません。受注者が点群を納品しても、開いて確認する手段が発注者側にない状態です。

**制度としても始まったばかりです。**

| | 適用開始 | 発注方式 |
|---|---|---|
| 鹿児島県 ICT土工 | 平成30年2月1日 | 発注者指定型・受注者希望型 |
| 鹿児島県 ICT法面工 | 令和3年3月2日 | 同上 |
| 鹿児島市 | 令和6年10月1日（試行） | 当面「受注者希望型」のみ |

市が「3次元で出せ」と指定した実績は制度上まだありません。
さらに市の試行要領は **災害復旧工事・維持補修工事・降灰除去工事を対象外** としています。
法面・治山・砂防・災害復旧を主戦場とする事業者ほど、3次元データを産まない工事を
多く抱えることになります。

**受注者側も、納品前に自分で確かめる手段が乏しい。**
点群と設計データを突き合わせて出来形を評価するには専用ソフトが要り、
現場の担当者が手元で確認できる状態にはなっていません。

---

## 2. 自社でここまで作りました

発注者が専用ソフトを入れずに、**ブラウザだけで点群を開いて出来形の合否まで
確認できる**ビューアを試作しました。動作する実物があります。

公開デモ： https://ryujiyasu.github.io/tengun-viewer/

![設計面とのズレを色で表示したところ](guide/capture/03-較差カラーマップ.png)

赤が設計より高い箇所（盛り気味）、青が低い箇所（削り気味）です。
**どこを見に行けばよいかが、図を開いた時点で分かります。**

### できること

- 点群（LAS / LAZ）と3次元設計データ（LandXML）を読み込み、設計面とのズレを算出
- 出来形合否判定総括表の作成（国土交通省「3次元計測技術を用いた出来形管理要領（案）
  令和8年3月版」様式-31-2 に準拠。天端・法面を部位ごとに判定、棄却点・計測密度・
  ばらつきまで算出）
- 判定結果の CSV 出力、断面図の作成
- 発注者へは **HTMLファイル1つ** を渡すだけ。インストールもインターネット接続も不要
- 3次元表示が使えない PC でも、平面図・断面図・帳票は見られる

### 実測値

合成した1工区分（出来形200万点・起工測量120万点）での実測です。

| | |
|---|---|
| 変換（点群読込〜判定〜出力） | 9.4 秒 |
| 表示（内蔵GPU・Intel UHD 630） | 60 fps |
| ブラウザのメモリ使用量 | 最大 273 MB |
| ブラウザ上での取り込み（50MBのLASを投入） | 14.6 秒 |

> 実際の工事データではまだ試していません。合成データでの値です。
> 実データ1工区での試行を葉月工業に依頼中です。

## 3. まだ解けていない技術課題

ここから先が、外部の力を借りたい部分です。
上記のビューアは「点群と設計データが揃っていれば評価できる」ところまでしか
解決していません。**実際の現場では、その前段で止まります。**

### (1) 点群の前処理が人手に頼っている

計測した点群には、草木・仮設物・重機・作業員・粉塵などが混ざります。
出来形を評価するには地表面だけを取り出す必要がありますが、この選別は
現状ほぼ手作業です。1工区あたり数時間かかることもあります。

法面工事では特に厄介です。吹付のり面・植生工・アンカー頭部など、
**「構造物なのか、除去すべき植生なのか」の判別が一般的な地面／非地面の
分類では効きません。**

→ 法面工事に特化した点群の自動分類。

### (2) 3次元設計データが無い工事が多い

出来形評価には3次元の設計面（LandXML など）が要ります。
しかし発注図は2次元の図面や紙で渡されることが多く、
3次元設計データは受注者が自分で起こしています。

→ 2次元図面・設計書から3次元設計面を自動生成する。
（今井様が進めておられる「役所からもらえるデータから施工計画書を作成」と
同じデータが入口になります）

### (3) 経年での比較ができていない

同じ法面を数年おきに計測しても、突き合わせる仕組みがありません。
点群同士の位置合わせと、植生の成長や季節変化を除いた「本当の変位」の抽出が
必要です。維持管理・防災に転用できるのはここからです。

→ 経年点群の自動位置合わせと変化抽出。

### (4) 完了検査後にデータが死蔵されている

検査が終わると点群はそのまま保管庫に入り、二度と使われません。
長崎県（令和5年3月）・和歌山県（令和5年3月）は既に県域の点群を
オープンデータとして公開しています。鹿児島でも同じ流れが来ると見ています。

## 4. 使えるデータ

| データ | 状況 |
|---|---|
| 過去工事の一覧 | 322件。うち296件に路線名・地名あり |
| 過去工事の点群 | 残存年次・形式を確認中 |
| 3次元設計データ | 工事により有無が異なる（確認中） |
| 出来形管理の実績 | 要領に沿った帳票の蓄積あり |
